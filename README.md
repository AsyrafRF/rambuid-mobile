# 🚦 RambuID

**RambuID** adalah aplikasi pintar berbasis AI yang dirancang untuk membantu pengendara dan masyarakat umum dalam mengenali dan memahami berbagai jenis **rambu lalu lintas di Indonesia** secara real-time melalui gambar, video, atau kamera langsung.

Dengan menggabungkan **teknologi pengolahan citra**, **pembelajaran mesin**, dan **kecerdasan buatan (AI)**, RambuID hadir sebagai solusi inovatif untuk meningkatkan keselamatan, kepatuhan, dan pengetahuan pengguna terhadap peraturan lalu lintas.

---

## 🎯 Fitur Utama

### 1. 🔍 Pengenalan Rambu Lalu Lintas Otomatis
Deteksi rambu secara real-time melalui:
- Upload **gambar** atau **video**
- **Live camera** saat berkendara  
Dilengkapi AI berbasis **YOLOv8** untuk akurasi tinggi.

### 2. 📚 Database Rambu Indonesia
Berisi:
- Rambu **peringatan**
- Rambu **larangan**
- Rambu **petunjuk**
- Rambu **informasi**  
Masing-masing dilengkapi deskripsi dan visualisasi.

### 3. 🎥 Input Data Fleksibel
- **Gambar**: Upload foto rambu.
- **Video**: Analisis video perjalanan.
- **Live Camera**: Deteksi rambu langsung dari webcam.

### 4. ℹ️ Penjelasan Rambu Otomatis
Setelah rambu dikenali, aplikasi akan:
- Menyebutkan **arti rambu**
- Menyediakan **peraturan terkait** seperti batas kecepatan, larangan parkir, dll.

### 5. 🚨 Peringatan & Notifikasi
Memberikan peringatan real-time saat mendekati rambu penting:
- Stop
- Bahaya
- Batas kecepatan  
Cocok untuk pengemudi aktif.

### 6. 🗺️ Peta Interaktif & Riwayat Deteksi
- Lokasi rambu yang pernah dikenali ditandai di peta.
- Menyediakan **riwayat dan statistik** deteksi rambu.

### 7. 🎓 Mode Edukasi
Fitur interaktif untuk belajar rambu lalu lintas, cocok untuk:
- Pelajar
- Pengemudi pemula
- Masyarakat umum

### 8. 🤖 Sistem Pembelajaran Mesin
RambuID menggunakan **machine learning** untuk terus berkembang dan mengenali rambu baru seiring waktu.

## 🌟 Manfaat Aplikasi

- ✅ **Peningkatan keselamatan berkendara**

## 🧠 Teknologi yang Digunakan

### 🔧 **Software**
- `Flutter` – Antarmuka aplikasi mobile
- `Python` – Backend AI & integrasi
- `Flask` – API Web untuk AI
- `OpenCV` – Pengolahan citra
- `YOLOv8 (Ultralytics)` – Model deteksi rambu
- `gTTS` – Teks ke suara untuk penjelasan rambu
- `Firebase` – Autentikasi & database pengguna
- `Google Colab` – Pelatihan dan eksperimen AI

### 🔩 **Hardware**
- `Raspberry Pi 4 Model B`
- `USB Webcam` – Input visual real-time
- `USB Speaker` – Output audio dari gTTS
- `Micro SDXC 64 GB`
- `Ublox Neo 6M` – GPS untuk lokasi rambu
- `MPU-6050` – Gyroscope untuk stabilisasi visual
